# Release Notes - Trevix Explorer v1.0.8

## Behavior Changes

- **Interactive Test Debugger**: You can now control test execution directly using _Pause_, _Resume_, and _Step Next_ controls available in both the desktop app Toolbar and the browser's _Floating In-Page HUD_.
- **Live In-Page HUD & Multi-Page Context**: The _Floating HUD_ updates test progress in real time across active browser tabs/pages, isolates sessions per `runId` without contaminating `window.name`, and prevents element hijacking during test runs.
- **Advanced LocatorResolver & SmartClick Self-Healing**:
  - Prioritizes element resolution inside active modals, supports dynamic UUID action healing, and resolves input targets via labels or placeholders.
  - Adds robust handling for **Datepickers** (programmatic fill on `readonly` inputs, auto-triggering closed calendar popups, and date cell self-healing) and **Dropdowns/Select2** (auto-opening closed menus and `<select>` synchronization).
  - Resolves table row action buttons (`detail`, `view`, `approve`) with row uniqueness checks and auto-confirms popup dialogs inside `smartClick`.

## Security

- Restricted **Auto-Healing** exclusively to read-only routes and actions, preventing automatic mutations on destructive actions (`delete`, `remove`, `cancel`, `reject`, `submit`).
- Added strict path validation to prevent directory traversal and secured runner download file name sanitization.
- Removed hardcoded internal IP addresses from the codebase and test suite.

## Fixed

- Isolated _In-Page HUD_ sessions per `runId`, eliminated `window.name` contamination, aligned HUD step counters with desktop indices, and prevented HUD elements from intercepting runner clicks.
- Fixed selector self-healing for sidebar menu items, preventing incorrect sidebar item labeling during test recording.
- Resolved compound selectors for table rows, handled whitespace variations, and prevented container text candidates from hijacking row action clicks.
- Implemented timeout self-healing for datepicker day cells and `role="option"` dropdown items, corrected option text extraction, and fixed `<select>` synchronization.
- Fixed JSON object formatting in `api_request` codegen to eliminate double stringification.
- Eliminated event bubbling to `body` when interacting with custom comboboxes or Select2 widgets.
- Added strict directory traversal protection in `DataDriverEngine` and modular sub-scenarios (`call_scenario`).
- Prevented premature popup tab auto-close during recording mode and enabled automatic `allowPopup: true` detection on `target="_blank"` links.
- Fixed React 19 render-time ref access in `DataDriverModal` dirty state comparisons.

## Added

- **Test Suite Orchestrator**: Multi-scenario batch automation runner with configurable target browsers, session modes (Isolated vs. Shared Login Context), auto-retry for flaky tests, and scenario filtering by `@tag`.
- **Data-Driven Testing (DDT Engine)**: Interactive built-in spreadsheet editor for CSV and Excel files located in `data/`, supporting dynamic parameter looping and variable tag interpolation.
- **Standalone CLI Runner (`trevix`)**: Native headless command-line interface for running individual tests (`trevix run`) and test suites (`trevix suite`) inside automated CI/CD pipelines with JUnit XML export.
- **Network Route Mocking & Stubbing**: Added `mock_route` action to intercept browser network requests and simulate API responses, errors, or custom payloads directly within test flows.
- **Automatic HAR Traffic Capture**: Auto-captures `.har` network traffic logs upon scenario failure for in-depth network diagnostics in Chrome DevTools.
- **Interactive Step-by-Step Debugger**: Integrated _Pause_, _Resume_, and _Step Next_ execution controls into the UI Toolbar and Floating HUD.
- **Multi-Language Support (i18n)**: Full bilingual interface support (English / Bahasa Indonesia) managed via application settings preferences.
- **Failure Screenshot Preview Modal**: Added quick action previews for failure screenshots directly inside Test Reports.
- **API Studio & Collection Runner Enhancements**: Full support for sending `x-www-form-urlencoded` and `form-data` request bodies in API Studio, Code Snippet Generator, and Collection Runner execution payloads.
- **Enhanced Recorder Support**: Automatic recording for Select2 components, Rich Text Editors (TinyMCE, CKEditor 4, Summernote, Quill), and icon-only buttons/links using `title` and `aria-label` attributes.
- **CI & Testing Integration**: Integrated GitHub Actions CI workflow (`ci.yml`) running automated integration test suites on Windows runners.

## Changed

- Updated the application visual theme to a vibrant orange palette and changed the application document title to **Trevix Explorer IDE**.
- Simplified target URL placeholders to `example.com` in `RecordModal` and `AddStepModal`.
- Extended `stepTextGenerator` to output clean, human-readable descriptions for all Playwright actions.
- Increased Playwright browser teardown timeout (`afterAll`) to 30 seconds to prevent flaky test runs.
