
## Behavior Changes

- **Strict Validation for Missing Upload Files and Dropdown Options**: File upload steps where the file does not exist on disk and dropdown select steps where the option cannot be found on the page now fail immediately (previously passed silently).
  - _Action required_: Make sure the upload file path exists on your computer. Advanced: a step in the `.spec.json` file can set `allowDummyFile` to `true` to allow a placeholder file. For dropdowns, verify that the option label or value exists in the select element.
- **Strict Element Presence on Assertions**: Asserting an element that does not exist in the DOM now fails immediately, even when expecting an empty string (`""`).
  - _Action required_: Ensure target elements are rendered on the page before running assertions.
- **Exact Whitespace Matching on Input Value Assertions (`toHaveValue`)**: Input value assertions no longer normalize or trim whitespace.
  - _Action required_: Ensure the expected value matches the exact input attribute value, including any leading or trailing spaces.
- **Default Popup and Tab Shielding**: All popups, background popunders, and new tabs (`target="_blank"`) are blocked by default to prevent navigation hijacking.
  - _Action required_: Enable the **"Buka tab baru"** option on click steps that intentionally open new browser tabs.
- **Faster Click Execution & Innermost Exact Text Priority**: Standard click actions execute immediately without waiting for popups, and element locators now prioritize innermost elements with exact text matching over outer containers.
  - _Action required_: Enable "Buka tab baru" if a click opens a new tab, and use exact text if targeting a nested button or label.
- **Required Environment Variables in Exported Playwright Scripts**: Exported standalone Playwright scripts now throw explicit runtime errors if required environment variables for secret fields are not set.
  - _Action required_: Set the required environment variables (e.g., `AUTH_PASSWORD="your_password"`) before running exported Playwright test scripts.
- **Secret Value Masking Across UI and Reports**: All secret and password values are masked (`••••••`) in UI step tables, Scenario Matrix preview, exported Excel sheets, HTML reports, and healing logs.
  - _Action required_: To update existing test scenarios with masked step descriptions, click "Generate from Steps" in the Scenario panel.
- **Localhost-Only API Mock Server**: The built-in API Mock Server now binds strictly to local loopback address `127.0.0.1` and does not accept remote network requests.
- **Strict Web Protocols for External Links**: Opening external URLs is restricted strictly to `http://` and `https://` web protocols.
- **Active Tab Switching & Auto-Recovery**: When clicking links with popup permission enabled, test execution automatically switches to the new tab, executes following steps in that tab, and returns to the last remaining open tab if the current tab closes.

## Security

- Masked secret values everywhere across the UI, scenario summaries, Excel reports, and interactive HTML logs.
- Enhanced intelligent secret detection for fields containing `passcode`, `passphrase`, `passkey`, `password`, `token`, `secret`, and `apikey` with boundary checks and false-positive filtering (e.g., passport, bypass).
- Generated clean, predictable environment variable names (`AUTH_PASSWORD`, `AUTH_USER_PASSWORD`) and isolated variable scoping to prevent naming collisions in exported Playwright scripts.
- Restricted the local API Mock Server strictly to loopback interface `127.0.0.1`.
- Blocked unauthorized URL protocols when opening links in external browsers.
- Protected project workspace files and API requests against path traversal security violations.
- Validated nested folder labels for saved API requests.

## Fixed

- Preserved active browser tab references across multi-step test runs after switching tabs.
- Synchronized popup permissions across browser windows and background tabs to prevent unexpected tab closures.
- Switched clipboard copying to the app's own copy function for stable copy operations.
- Added 8-second polling retry with whitespace normalization for `toHaveText` and `toContainText` assertions, and strict raw evaluation for `toHaveValue` input assertions.
- Added URL assertion match modes (`exact`, `contains`, `regex`) with instant page load confirmation.
- Captured and displayed detailed error messages when text assertion elements are not found.
- Explicitly failed test execution when uploaded files or dropdown options cannot be found.

- Manual "Rahasia (sembunyikan nilai di log dan ekspor ke env)" checkbox on form fill modal dialogs.
- Safe dynamic template token evaluation and escaping for Playwright script generation.
