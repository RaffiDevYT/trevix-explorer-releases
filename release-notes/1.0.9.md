# Release Notes - Trevix Explorer v1.0.9

## Behavior Changes

- **Intelligent CRUD & Sub-Module Auto-Ordering**: Test Suites now automatically detect and sequence scenario dependencies based on the CRUD lifecycle (`datatable` -> `add` -> `detail` -> `edit` -> `delete`). Destructive delete actions are strictly scheduled last to prevent state corruption.
- **Deep Step Intent Analyzer**: When test filenames or metadata are arbitrary (e.g., `tc01`, `flow_a`), the runner analyzes the actual button clicks and form inputs (`Save`, `Hapus`, `Edit`, `Submit`) within steps to determine execution order accurately.
- **Master-Detail Scenario Detection**: Automatically detects when child entity creation depends on navigating through a parent record's `detail` page, ensuring the parent view is executed before child `add`/`edit`/`delete` actions.
- **Smart Session Persistence & Login Bypass**: When running multi-scenario suites with shared sessions (`isolateSession: false`), the runner automatically detects pre-authenticated sessions and skips redundant login steps to avoid login redirection failures.
- **Step-Level Self-Healing Retries in Suites**: Added in-place step retries (up to 2 retries with 400ms pacing) for action steps in suite runs, aligning suite stability with single-case execution against transient DOM delays.
- **Interactive Pause on Failure (Debug Mode)**: Added a dedicated 'Pause on Failure' toggle policy. When a scenario fails, the runner holds the browser context alive, presenting real-time interactive actions ('Skip & Continue', 'Retry Scenario', 'Stop Suite') with a 5-minute safety timeout.
- **Rerun Failed Scenarios Only**: Added a one-click toolbar action ('Rerun Failed') upon suite completion when failures occur, allowing immediate re-testing of failed scenarios without re-running successful ones.

## Security

- **Intranet Popup Tab Shielding**: Added a 6-second protection grace window and private network IP whitelisting (`192.168.*`, `10.*`, `172.*`, `localhost`) to prevent premature popup tab termination during enterprise intranet test automation.
- **Browser Context Listener Cleanup**: Enforced strict `removeAllListeners('page')` cleanup on browser contexts after every scenario attempt to prevent memory leaks and zombie event handlers.
- **Action Whitelist Extension**: Added `call_scenario` and `mock_route` to scenario validation allowed actions to prevent false positive security rejections.

## Fixed

- **Popup Tab Termination on Intranet Navigation**: Resolved an issue where newly spawned browser tabs on intranet targets were forcefully closed before completing initial navigation.
- **Session Collision in Multi-Scenario Suites**: Fixed failures where subsequent scenarios failed to enter credentials because the browser was already authenticated (`isolateSession: false`).
- **Missing Step-Level Retries in Suites**: Added `MAX_STEP_RETRIES = 2` with 400ms delay to prevent suite scenarios from failing immediately on minor DOM transition delays.
- **Ignored SlowMo Execution Delay**: Resolved an issue where Test Suites ignored user-configured slow-motion delay preferences from settings.
- **Misleading Static Diagnostic Alert Banner**: Replaced the static, hardcoded failure alert banner in Suite Modal with dynamic real-time diagnostics showing the exact failed scenario name, real error message, and contextual solution hints.
- **Awkward Console Log Path Wrapping & False Red Styling**: Fixed Windows file paths wrapping awkwardly and turning red in the suite execution console output due to regex substring matching.
- **False Positive Security Violation in Scenario Validator**: Fixed false security rejections for scenarios containing `call_scenario` and `mock_route`.
- **Browser Context Listener Leaks**: Prevented listener leaks by properly detaching and removing page listeners between suite scenarios.
- **Unhandled Crash on Manual Browser Close**: Added a graceful `disconnected` event handler preventing crashes if users manually close the browser during suite execution.
- **Graceful Fallback for Missing FFmpeg**: Prevented runner crashes when video recording is enabled but the FFmpeg binary is missing on the system.
- **Orphaned Zombie Processes**: Added automated process cleanup (`ProcessCleaner`) to safely kill leftover browser/driver processes on test cancellation or exit.
- **Ambiguous Scenario Naming**: Generic scenario names (e.g., `detail`, `test`) in multi-module projects are now clearly prefixed with their parent module folder name.
- **Duplicate Phantom File Upload Step**: Fixed an issue in `RecorderEngine` where clearing or blurring a file input triggered an unintended second `upload_file` step with a dummy fallback filename (`sample_upload.xlsx`).
- **Clipped Sidebar Context Menu**: Fixed an issue where the right-click context menu on sidebar files was clipped at the bottom of the viewport, hiding the Delete option when right-clicking files near the bottom of the window.
- **Upload File Path Candidate Resolution**: Added `data/`, `uploads/`, and `fixtures/` directories in the workspace root to `smartUploadFile` candidate search paths, ensuring DDT attachments and fixture files are discovered seamlessly across machines.
- **Clipped 3-Dots Action Menu**: Added dynamic viewport boundary detection to file and folder 3-dots action menus in the sidebar, automatically opening upward (`bottom-full mb-1`) when near the bottom of the screen.

## Added

- **Revamped Suite Console Output Terminal**: Modernized the execution log viewer with line numbers, categorized badges (`[FAIL]`, `[PASS]`, `[START]`, `[SUITE]`, `[REPORT]`, `[SCREENSHOT]`, `[STOP]`), one-click interactive buttons to open HTML reports and view failure screenshots, a copy-all-logs button, and a clear console button.
- **Auto-Detect Order Action in Suite Modal**: Added an **Auto-Detect Order** toolbar button with instant toast feedback for one-click scenario reordering. New suites now automatically order scenarios upon creation.
- **Base URL Batch Replacer**: Added a workspace utility dialog (`BaseUrlModal`) to bulk find and replace target host URLs across all recorded scenarios in the workspace.
- **Zombie Process Cleaner Engine**: Added cross-platform background process termination (`ProcessCleaner`) to safely clean up orphaned browser and driver processes upon test abort or exit.
- **Confirm Close All Tabs Dialog**: Added a safety modal when closing multiple active editor tabs with unsaved changes.
- **Full Editor TabBar & Console Overhaul**: Enhanced TabBar with tab pinning, dirty state badges, horizontal scrolling, and integrated log category badges in the main Editor Console.
- **Redesigned Settings & Preferences**: Modernized system preferences into a clean two-column structured layout with dedicated sections for General, Network & API, Editor & Code, Automation & E2E, and About Trevix.
- **Test Execution Timestamp Badge**: Added a date and time badge (`📅 DD MMM YYYY, HH:mm:ss`) to both single scenario test summary and Suite Modal header, displaying exactly when the tests were executed with persistence.

## Changed

- Cleaned up suite status summaries to use dash separators instead of pipe characters (`-` instead of `|`).
- Upgraded and expanded internationalization (English & Indonesian) for all new suite, runner, and preference controls.
