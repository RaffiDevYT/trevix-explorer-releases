# Security Policy

## Supported Versions

| Version | Supported          |
| ------- | ------------------ |
| v1.0.x  | :white_check_mark: |
| < v1.0  | :x:                |

## Reporting a Vulnerability

We take the security of Trevix Explorer seriously. If you believe you have found a security vulnerability in any Trevix Explorer release or distribution binary:

1. Please do not report security vulnerabilities through public GitHub issues.
2. Instead, report security advisories directly to **Raffi Studios** via GitHub Private Vulnerability Reporting or email support.
3. You will receive a response within 48 hours with a preliminary assessment and remediation plan.
